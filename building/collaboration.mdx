## Built-in collaboration

Gainable apps can include collaboration features that work out of the box. Ask for them in natural language, on a page or on every record.

## Available features

### Team chat

Real-time messaging for groups.

```text
"Add a team chat to the project page"
"Include a group chat for discussing deals"
```

What you get:
- Real-time messaging
- Message history
- Typing indicators
- Read receipts
- Emoji reactions
- File sharing in chat

Best for team discussions, and for a conversation that belongs to one project, deal or task.

### Direct messaging

Every app has the Messenger built in: the chat icon in the app's header opens direct and group conversations with the people in your Gainable account. There's nothing to prompt for. If you ask Gaia to add messaging, it tells you it's already there. See [the Messenger](/use/notifications#messenger).

<Note>
**Chat vs Messenger:**
- Use **Chat** for a conversation that belongs to a page or a record (project chat, team chat). Gaia builds it where you ask.
- The **Messenger** is for private conversations between people, like Slack DMs. It's always in the header.
</Note>

### File sharing

Upload and share documents.

```text
"Add file sharing to the project"
"Let users upload documents to deals"
```

What you get:
- File upload (drag and drop)
- File previews
- Download options
- File type icons
- Version history
- File organization

### Comments

Discussion threads on specific items.

```text
"Add comments to tasks"
"Let users comment on deals"
```

What you get:
- Threaded discussions
- Mentions (@user)
- Timestamps
- Edit and delete
- Reactions

### Activity feeds

Social-style updates and announcements.

```text
"Add an activity feed to the dashboard"
"Include a news feed for team updates"
```

What you get:
- Post creation
- Comments on posts
- Reactions
- Rich text formatting
- File attachments
- Chronological feed

### The Assistant

Every app has its own [Assistant](/use/assistant), so you don't need to ask for one. People can mention it in a record's comments to get help right there, or bring colleagues into a chat with it.

<Info>
**The Assistant vs team chat:** The [Assistant](/use/assistant) is your app's AI teammate. It answers from the app's data and does work in it. Team chat is human-to-human messaging. You can use both in the same app.
</Info>

## How to request collaboration

Simply describe what you want in natural language:

<CodeGroup>
```text Chat
"Add a team chat to the project page"
"Include chat for discussing deals"
"Add group messaging"
```

```text Files
"Add file sharing"
"Let users upload documents"
"Include file attachments"
```

```text Comments
"Add comments to tasks"
"Let users discuss items"
"Include threaded comments"
```

</CodeGroup>

## Where to place collaboration

You can add collaboration features to specific contexts:

### Page-level chat

```text
"Add a team chat to the dashboard page"
```

Everyone on that page sees the same chat.

### Item-level chat

```text
"Add a chat for each project"
```

Each project has its own separate conversation. The same works for files and comments:

```text
"Add files to each deal"
"Add comments to each task"
```

### Layout

Say how a feature should appear on the page:

- **Inline**: in the main content area. `"Show the chat in the main content area"`
- **Drawer**: sliding out from the side. `"Show files in a right panel"`
- **Tab**: one tab among several. `"Tabs: Overview, Chat, Files, Comments"`

## Notifications

Collaboration features include notifications:

- **Toast notifications** - Pop-up alerts for new messages
- **Badge counts** - Unread message indicators
- **Sound alerts** - Optional audio notifications

People are notified about new messages in their chats, @mentions in comments, replies to their posts, and files shared with them. Every app also has the notification bell built in, in the header next to the Messenger. See [Notifications](/use/notifications).

<Note>
Notifications are enabled by default. Users can manage their preferences.
</Note>

## User presence

See who's online and active:

- **Online indicators** - Green dots for active users
- **Typing indicators** - See when someone is typing
- **Last seen** - Know when users were last active

## Best practices

### Choose the right feature

| Need | Use |
|------|-----|
| Team discussions | Chat |
| Private conversations | The Messenger (built in) |
| Document collaboration | Files |
| Item-specific discussions | Comments |
| Announcements | Posts/Feed |

### Place chat contextually

<CodeGroup>
```text Good
"Add a chat to each project page for project-specific discussions"
```

```text Less useful
"Add chat" (without specifying where)
```
</CodeGroup>

### Combine features

```text
"Add to each project:
- Team chat for discussions
- File sharing for documents
- Activity feed for updates"
```

## Example integrations

### Project management

```text
Build a project tracker with:
- Projects with name and status
- Tasks for each project

On the project detail page, add:
- Team chat for discussions
- File sharing for documents
```

### CRM

```text
Build a CRM with:
- Companies and contacts
- Deals linked to companies

On each deal page, add:
- Comments for internal notes
- File attachments for proposals
```

### Team dashboard

```text
Build a team dashboard with:
- Activity feed for announcements
- Team chat for discussions
- File area for shared documents
```
