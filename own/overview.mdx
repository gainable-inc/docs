Once an app is built, its owners decide who uses it, what each person sees, and how its data and Assistant behave. Most of this lives in the builder: open your app at [build.gainable.dev](https://build.gainable.dev) and use the icons in the left rail.

## Where things are

| You want to | Go to |
|-------------|-------|
| Change the app | The builder chat. See [Changing a built app](/prompting/refining). |
| Make changes live | **Publish** in the builder. It shows a dot when there are changes that aren't live yet. |
| Decide who gets in | The people icon in the builder's left rail. |
| See the data behind the app | The database icon in the builder's left rail lists the app's collections. See also [Datasets](/build/datasets). |
| See what happened | The clock icon in the builder's left rail. |
| Sync the app's data | The **Data** icon in the app's header. |
| Set up the Assistant | **Assistant** in the app's sidebar, then **Scheduled**, **Memory** or **Connectors**. |
